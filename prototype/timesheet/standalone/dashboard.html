What it actually saw

The raw layer for one day. Dots are individual signals — a file touched, a reply sent, a channel post, a call attended. Bars above them are the blocks the engine cut from those signals: first by time, then again wherever the subject of the work changed.

Where the review effort goes

The unassigned rows are the product working, not failing. Below is the one that matters: a newly opened engagement the firm has no rules for yet. One correction is all the system gets, so it has to extract every reusable rule from it.

How it works

01

Normalise

Connectors turn calendar entries, call records, file activity, mail, tickets, commits and agent sessions into one signal shape: when, what subject, which folder, which counterparty, which link back. Metadata only.

02

Segment

Signals become blocks of real working time. The tolerated gap flexes with signal density, so reading and reviewing counts as work — but never stretches across a lunch break.

03

Attribute

Each block is scored against every engagement. The winner, the runner-up it beat, the margin between them and the individual records behind each are all retained. A keyword alone never wins.

04

Draft

Blocks become rows at the firm's rounding policy — redistributed so the day's total is preserved — with a description grounded strictly in the evidence, and unexplained time left visible.

What this deliberately does not do

The failure mode for this category is not missing an hour. It is confidently billing the wrong client, or reading like surveillance to the people it runs on. Both are design problems, so they are answered in the design.

No keystroke or screen capture. The default signal set is what the tenant already records for compliance. The desktop focus agent is optional, local, and off.

No document contents. Signals carry titles, paths and counterparty domains. The engine never needs to read a file to place it.

No silent submission. Nothing is filed without a human accepting it. The draft is a starting point, not an assertion.

No invented hours. Rounding redistributes within a day and never inflates its total; unattributed time stays its own row.

No cross-billing. A sub-threshold fragment pools only into a row of the same chargeability — non-chargeable minutes cannot drift onto a client's bill.

No learning from ambiguity. A correction on a block with two outside parties teaches nothing: a wrong rule misbills every future thread with that counterparty.

Synthetic data throughout — Northgate Advisory and its clients are fictional. Every hour, confidence label and evidence row on this page is produced at build time by the engine in src/core/timesheet/, not authored by hand.
