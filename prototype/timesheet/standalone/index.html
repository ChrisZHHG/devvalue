The thing nobody uses

The week was never actually lost.

Every dot is a trace the work already left, in a system the firm already runs: a meeting attended, a file touched, a reply sent, a ticket moved. Nobody logged any of it. It is a by-product.

Why this is not an app you install

The traces are at the top. So the tool has to be, too.

Every attempt at this problem that starts on an individual's machine hits the same three walls. None of them are engineering walls.

Per-person tool

Each person installs, configures, and grants. Each install is a separate negotiation.

One connection at the top

One consent, once, by one administrator. Everyone downstream just receives a draft.

Wall 1 · Permission

Nobody can install this for themselves

Tenant-wide read scopes need a Global Administrator. Large firms switch user consent off entirely — so even a read-only view of your own calendar cannot be self-served. There is no bottom-up path. There is only a top one.

Wall 2 · Privacy

Watching a person is surveillance. Reading the tenant is not.

A keystroke or screen agent on a laptop is a works-council fight and it deserves to be. At the tenant layer the tool reads only what the firm already logs for compliance — titles, folders, counterparties. Never contents.

Wall 3 · Taxonomy

The project structure is a firm-level fact

Which folder, which client domain, which engagement code — that already exists, once, for the whole firm. Asking each person to describe their own projects is asking 4,000 people to re-enter one thing.

How it reads a day

Four steps. No magic in any of them.

The whole method is: stop guessing about people, and start reading the shape of the traces. Each step answers exactly one question.

The part that decides whether anyone trusts it

It has to be able to say “I don't know.”

The failure that kills this category is not a missed hour. It is confidently billing the wrong client. So a word in a subject line is never allowed to win on its own — only a folder, a counterparty domain, a repository or a ticket project can place time on a bill.

And the unit itself is breaking

When an agent does the work, hours stop measuring it.

Thursday of this week was an analytics build for a client. Part of it was a person thinking. Part of it was an AI agent working. Both were billable delivery. Only one of them is an hour.

This is why the engine underneath is shared with DevValue, which measures the same thing for software teams. Reconstructing hours is the near-term product; measuring delivery when hours stop being the unit is the reason it matters.
